# ESP8266 Conway's Game of Life
The code won't work as is as you need to change variable 'ssid' (line 18) to your internet and 'password' (line 19) to your internet's password. For the web server to work, you have to use the same internet as defined in the code. After ESP8266 connects to the internet, it will display an IP address to you, type that in a browser and you'll be good to go.
